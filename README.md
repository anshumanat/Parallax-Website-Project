# Parallax Website

A simple and responsive Parallax website built using only **HTML** and **CSS**. It features smooth scrolling and background effects that create a visually appealing experience.

## 🌟 Features

- Parallax scrolling effect using pure CSS
- Clean and minimal design
- Fully responsive layout
- Easy to customize and extend

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**

No JavaScript or frameworks required.
